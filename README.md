## ขั้นตอนการรันโปรเจกต์ (Getting Started)

1. เข้าไปยังโฟลเดอร์โปรเจกต์ `finalWeb1106`

```bash
cd finalWeb1106
```

2. ติดตั้ง Dependencies (กรณีใช้งานครั้งแรกหรือยังไม่ได้ติดตั้ง)

```bash
npm install
```

3. เริ่มต้นรันเซิร์ฟเวอร์สำหรับการพัฒนา (Development Server)

```bash
npm run dev
```

4. เปิดเว็บเบราว์เซอร์และเข้าไปที่ URL ด้านล่างเพื่อเข้าสู่ระบบ

```text
http://127.0.0.1:3000
```
